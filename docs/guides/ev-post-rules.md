# 전기차 차종 글 규칙 (ev-post-rules.md)

> 전기차 차종 글(`/post <차종>`)에만 적용한다. style-guide, seo-guide, image-guide와 **충돌하면 이 문서가 우선**한다.
> 마지막 수정: 2026-11-05 (사용자 지시 반영)

---

## 1. 제목 [필수]

* 제목은 **차량 모델명만** 쓴다. 예: `테슬라 모델 Y`
* "가격·보조금 총정리" 같은 꼬리를 붙이지 않는다. 메인 키워드는 모델명이다.
* 썸네일 이미지의 큰 제목도 모델명을 중심으로 한다.

## 2. 분량과 밀도 [필수]

* **포인트만 남기고 줄인다.** 산만하고 길면 안 된다. 본문은 공백 제외 약 1,500~2,500자를 목표로 한다. (seo-guide 5-1의 1,500자 이상은 지킨다)
* 소제목 하나는 **이미지 + 2~4문장**이 기본이다. 같은 숫자를 이미지·표·문장에서 세 번 반복하지 않는다.
* 표는 꼭 필요한 곳에만 둔다. 숫자가 많은 소제목은 이미지가 요약을 맡고, 문장은 해석과 주의점만 쓴다.
* 확인하지 못한 값은 길게 설명하지 말고 "확인하지 못했다" 한 줄과 확인할 곳만 적는다.

## 3. 소제목 구성 [필수]

* **각 소제목(`###`)은 요약 이미지로 시작하고, 이미지 아래에 설명 문장을 쓴다.** 소제목이 없는 대제목(1장, 5장)은 대제목 바로 아래에 이미지를 둔다.
* 이미지 마커는 소제목 제목 바로 다음 줄에 `[IMAGE: ...]`로 넣는다. 맨 위 썸네일은 그대로 둔다.
* 이미지에는 그 소제목의 핵심 숫자·결론만 담는다(image-guide 2장 글자 규칙).
* 이 규칙 때문에 이미지가 10장을 넘을 수 있다. 이 문서가 seo-guide 7장의 5~10장 권장보다 우선한다.

## 4. 표 [필수]

* **모든 표는 가운데 정렬**이다. 마크다운 표 구분선은 `| :---: |`로 쓴다.
* 복사용 페이지(`tools/make_copy_page.py`)는 표 칸을 항상 가운데 정렬로 만든다.
* 이미지 안의 표도 글자를 가운데 정렬한다(`text-align:center`).

## 5. 고정 목차 (차종마다 같은 틀)

```
제목: [차 이름]

1. 가격과 보조금      트림별 가격 / 보조금 구조 / 실구매가 확인 방법  → 한 개의 표로 일목요연하게
2. 주행거리와 충전    인증 주행거리 / 겨울철 주행거리 / 급속·완속 충전 시간
3. 이슈 및 알려진 문제  배터리 보증 / 리콜과 공식 공지 / 실사용자들 후기
4. 경쟁 차종과 비교    같은 급 차종 비교표 / 이 차의 차이점
5. 요약 마무리 및 구매 전 체크리스트
```

* 대제목 이름 뒤에 `- 질문형 부연`을 붙인다(style-guide 4장). 소제목 이름은 위 문구 그대로 쓴다.
* 5장 제목은 `## 5. 마무리 - 요약과 구매 전 체크리스트`로 쓴다(style-guide의 `N. 마무리` 규칙 유지).
* 1장은 소제목 없이 표 한 개(가격·국비·지방비·실구매가)로 합치고, 국비 지원 구간과 확인처를 짧게 덧붙인다.

## 6. 사실 규칙 [필수]

* 가격·보조금·주행거리·보증·리콜 같은 숫자는 확인한 출처가 있는 값만 쓴다. 확인 일자를 글 앞부분에 한 번 적는다.
* 확인하지 못한 항목(예: 충전 출력, 일부 트림 보증)은 숫자를 지어내지 않는다.
* 실사용자 후기는 열어서 읽은 자료나 검색 요약에서 **여러 곳에 반복되는 의견**만 쓰고, 출처 URL은 메타 주석에 남긴다. 열어 보지 못한 원문은 메타 주석에 그렇게 적는다.
* 경험 문장은 style-guide 10장 방식으로 2~4곳만 쓴다. 지어낸 수치·인물은 쓰지 않는다.
