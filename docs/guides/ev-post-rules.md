# 전기차 차종 글 규칙 (ev-post-rules.md)

> 전기차 차종 글(`/post <차종>`)에만 적용한다. style-guide, seo-guide, image-guide와 **충돌하면 이 문서가 우선**한다.
> 마지막 수정: 2026-11-05 (사용자 지시 반영: 새 목차, 요약 카드 이미지 폐지, 차량 사진 사용)

---

## 1. 제목 [필수]

* 제목은 **차량 모델명만** 쓴다. 예: `테슬라 모델 Y`
* "가격·보조금 총정리" 같은 꼬리를 붙이지 않는다. 메인 키워드는 모델명이다.

## 2. 분량과 밀도 [필수]

* **포인트만 남기고 줄인다.** 산만하고 길면 안 된다. 본문은 공백 제외 약 1,500~2,000자를 목표로 한다. (seo-guide 5-1의 1,500자 이상은 지킨다)
* 소제목 하나는 **표 한 개 + 1~3문장**이 기본이다. 같은 숫자를 표와 문장에서 두 번 쓰지 않는다.
* 확인하지 못한 값은 길게 설명하지 말고 "확인하지 못했다" 한 줄과 확인할 곳만 적는다.

## 3. 이미지 [필수]

* **표와 같은 내용을 이미지로 또 만들지 않는다.** 요약 카드·비교표 이미지는 만들지 않는다. 숫자와 비교는 표가 맡는다.
* 이미지는 **해당 차량의 실제 사진**만 쓴다. 대표 사진 1장은 필수, 추가 사진은 있으면 1~2장까지 쓴다.
* 사진은 **출처와 라이선스가 확실한 것만** 쓴다. 우선순위: CC0·퍼블릭 도메인 > CC BY(저작자 표시) > 그 외는 쓰지 않는다. CC BY-SA, 비영리(NC)·변경금지(ND) 라이선스는 쓰지 않는다.
* **알아볼 수 있는 사람 얼굴, 읽히는 번호판, 다른 회사 로고가 크게 나온 사진은 쓰지 않는다.** 판매 중인 현행 모델(연식·외관)과 다른 사진도 쓰지 않는다.
* 사진 바로 아래 줄에 `사진: 저작자, 라이선스, 출처(Wikimedia Commons 등)`를 본문 문장으로 적는다. 파일 원본 주소와 라이선스 확인일은 메타 주석에 남긴다.
* 사진은 내려받은 원본을 가로 1080px로 줄여 `docs/drafts/images/<슬러그>/`에 `NN_photo_슬러그.jpg`로 둔다. 글자·도형을 덧씌우지 않는다.
* 사진을 구하지 못하면 만들어 내지 말고 마커 `[IMAGE: 사진 | 설명: ...]`만 남기고 보고한다.

## 4. 표 [필수]

* **모든 표는 가운데 정렬**이다. 마크다운 표 구분선은 `| :---: |`로 쓴다.
* 복사용 페이지(`tools/make_copy_page.py`)는 표 칸을 항상 가운데 정렬로 만든다.

## 5. 고정 목차 (차종마다 같은 틀)

```
제목: [차 이름]

1. 가격과 보조금      트림별 가격 + 보조금(국비·지방비) + 실구매가 → 표 1개
2. 인증 주행거리      평소(상온)와 겨울철(저온) 비교표
3. 충전 시간          급속·완속 표
4. 최근 이슈          간단히 3개 (가격 변동, 결함·하자, 리콜 등)
5. 평판               장점 3개, 단점 3개 → 표 1개
6. 마무리             최종 요약과 구매 전 체크리스트
```

* 대제목 이름 뒤에 `- 질문형 부연`을 붙인다(style-guide 4장). 6장 제목은 `## 6. 마무리 - 요약과 구매 전 체크리스트`로 쓴다(style-guide의 `N. 마무리` 규칙 유지).
* 각 대제목 안에는 소제목(`###`)을 따로 두지 않는다. 표 한 개와 짧은 설명으로 끝낸다.

## 6. 사실 규칙 [필수]

* 가격·보조금·주행거리·충전·리콜 같은 숫자는 확인한 출처가 있는 값만 쓴다. 확인 일자를 글 앞부분에 한 번 적는다.
* 한국 공식 값이 없고 해외 시험·블로그 값만 있으면, 표에 **"참고값"이라고 표시하고 근거 종류(해외 시험, 블로그)를 같이 적는다.** 공식 값처럼 쓰지 않는다.
* 평판(장점·단점)은 열어서 읽은 자료나 검색 요약에서 **여러 곳에 반복되는 의견**만 쓰고, 출처 URL은 메타 주석에 남긴다. 열어 보지 못한 원문은 메타 주석에 그렇게 적는다.
* 경험 문장은 style-guide 10장 방식으로 0~2곳만 쓴다. 지어낸 수치·인물은 쓰지 않는다.
